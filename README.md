**System Design Basics Notes :**


Vertical Scaling : Improving a single resource to increase output (e.g., asking one chef to work harder).
Preprocessing : Optimizing workflows by preparing tasks during non-peak hours using cron jobs.
Resilience & Backups : Eliminating single points of failure by having backup resources ready.
Horizontal Scaling : Adding more machines or staff to handle increased demand.
Microservices : Dividing a large system into smaller, specialized services to improve maintenance and scaling.
Distributed Systems : Spreading operations across multiple locations to increase fault tolerance and reduce response latency.
Load Balancing : Using a central authority to route requests to the most efficient resource based on real-time data.
Decoupling : Separating components so they can operate independently, making the system more flexible.
Monitoring : Using logging and metrics to identify issues and optimize performance.
Extensibility : Designing systems that can adapt to new business requirements without needing a total rewrite.
